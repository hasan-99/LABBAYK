# لَبّيك | LABBAYK

مشروع توصيل وشراء احتياجات يومية عند الطلب، يبدأ في دمشق وريف دمشق. التطبيق مبني كـmonorepo: تطبيق Expo Router مشترك للويب وReact Native، ولوحة إدارة مستقلة بـReact وVite.

مستودع GitHub الخاص: https://github.com/hasan-99/LABBAYK

## ملفات المشروع

- `MASTER_PLAN.md` — نطاق المنتج، البنية التقنية، الأدوار، تدفقات العمل، الأمان، الحسابات، الاختبارات، مراحل التنفيذ ومعايير الإنجاز.
- `DESIGN.md` — الهوية البصرية، مكونات الواجهة، الشاشات المطلوبة، دعم العربية وRTL ومتطلبات الإنترنت الضعيف.
- `IMPLEMENTATION_STATUS.md` — سجل الإنجاز والتحقق والعوائق.
- `IMPLEMENTATION_ROADMAP.md` — تقسيم التنفيذ إلى مراحل ومعالم قبول.

## ترتيب البدء

1. راجع `DESIGN.md` و`MASTER_PLAN.md` بالكامل قبل كتابة الكود.
2. افحص المستودع والبيئة؛ أنشئ هيكل monorepo فقط إذا كان المجلد لا يحتوي مشروعاً قائماً.
3. نفّذ المراحل M0 إلى M7 بالتتابع، وسجّل النتائج الفعلية في `IMPLEMENTATION_STATUS.md`.
4. لا تعتبر أي وظيفة مكتملة قبل التحقق منها وفق بوابة المرحلة ومعايير الإنجاز في الخطة.

## أوامر التطوير

- `pnpm install`
- `pnpm dev:web` — تطبيق Expo للويب (ومتوافق مع Android/iOS).
- `pnpm dev:admin` — لوحة الإدارة.
- `pnpm build:web` و`pnpm build:admin` — بناء تطبيقي الويب.

المشروع متصل بقاعدة Supabase `LABBAYK` ضمن منظمة `hasan-99` على الخطة المجانية. إعدادات العميل العامة محفوظة محلياً في `.env.local` وغير متعقبة في Git. العميل والسائق ينشئان حساباً بالبريد وكلمة السر، ويؤكدان البريد برمز من 8 أرقام عند التسجيل فقط؛ الدخول اللاحق بالبريد وكلمة السر. الحد الأدنى لكلمة السر 8 أحرف. السائق يحتاج دعوة وموافقة الإدارة، والمدير يدخل ببريده وكلمة السر ودور `super_admin`. لا يحتاج هذا التدفق SMS أو Twilio.

### تسجيل الدخول بالبريد

العميل والسائق يؤكدان بريدهما مرة واحدة أثناء إنشاء الحساب، وبعدها يستخدمان كلمة السر للدخول. استعادة كلمة السر متاحة عبر البريد. إعداد SMTP المخصص من Gmail وقالب `Confirm signup` ذي الرمز `{{ .Token }}` مفعّلان في المشروع المستضاف. بيانات SMTP السرية تبقى في Supabase ولا تُحفظ في الواجهة أو المستودع. اختُبرت رحلة تسجيل العميل وتسجيله اللاحق بالبريد وكلمة السر؛ واختُبر تسجيل السائق بدعوة ثم بقي بانتظار مراجعة الإدارة.

#### إعداد SMTP الحالي

يستخدم SMTP الحالي `smtp.gmail.com` عبر TLS. الإعداد مجاني للتجارب المحدودة، لكن Gmail الشخصي قد يؤثر على وصول الرسائل؛ حد Supabase المضبوط حالياً 30 رسالة بالساعة. راقب وصول الرسائل قبل فتح التسجيل على نطاق واسع. إرشادات [Google لكلمات مرور التطبيقات](https://support.google.com/accounts/answer/185833?hl=en) و[حدود Gmail](https://support.google.com/mail/answer/22839?hl=en) و[SMTP في Supabase](https://supabase.com/docs/guides/auth/auth-smtp).

ملاحظة أمنية: Security Advisor يظهر تحذيراً واحداً لأن حماية كلمات المرور المسرّبة تتوفر على خطة Pro وما فوق، وهي غير مفعّلة على الخطة المجانية [بحسب توثيق Supabase](https://supabase.com/docs/guides/auth/password-security). لا توجد فحوص Health مفتوحة. تفاصيل التحقق والعوائق الحالية في `IMPLEMENTATION_STATUS.md`.
